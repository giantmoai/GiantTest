# Simple Vocab Helper Chrome Extension

This extension shows a random vocabulary word with a short description each time you open the popup. It is aimed at helping young English learners practice simple words.

## How to use

1. Open Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** in the top right.
3. Click **Load unpacked** and select the `extension` folder in this repository.
4. A new toolbar icon will appear. Click it to see a word and its meaning.
